# ことばル

Discord Activity向けの、日本語5文字を6回以内で当てる単語ゲームです。

## 現在実装済み

- 5文字 × 6回の盤面
- 正位置=緑、含むが別位置=黄、不使用=灰
- 重複文字をWordle方式で正しく判定
- ひらがな入力をカタカナへ正規化
- 「ことのはたんご」A_data_new.csv 47,015語を入力判定辞書として同梱
- Q_fil_ippan.csvを日替わり出題候補として利用
- 日本語UI
- 回答ごとのタイル反転演出
- 当日の途中経過をlocalStorageへ保存
- Discord Embedded App SDK認証の土台
- プレイ終了時に結果だけをDiscordの非公開記録チャンネルへ保存
- 毎日0:05（日本時間）に前日の結果をDiscordへ自動投稿

## Discordを「一時DB」にする方式

`KOTOBARU_LOG_CHANNEL_ID` に指定した非公開チャンネルへ、終了結果をBotメッセージとして保存します。保存するのは日付、問題番号、DiscordユーザーID、表示名、正解回数、緑/黄/灰パターンだけです。推測した単語や正解語そのものは保存しません。

翌日0:05に前日分を読み込み、`KOTOBARU_SUMMARY_CHANNEL_ID` に「昨日の結果」を投稿します。累積勝率・連続記録・長期DBは使用しません。

- `postYesterdaySummary()`
- `cron.schedule(...)`

## 辞書ライセンス

同梱辞書は「ことのはたんご」プロジェクト由来です。元プロジェクトのライセンス・帰属表示を確認し、非営利条件を守って利用してください。

## v0.2 追加ルール：五十音の「行」ヒント

ことばル独自ルールとして、緑・黄・灰に加えて薄紫を追加しました。

- 緑：文字と位置が一致
- 黄：同じ文字が別の位置に存在
- 薄紫：文字そのものは違うが、同じ五十音の行に属する文字が別の位置に存在
- 灰：上記のいずれにも該当しない

判定の優先順位は **緑 → 黄 → 薄紫 → 灰** です。同一文字・同一行の重複がある場合も、本家Wordleと同様に正解側の文字を一度ずつ消費してヒントを出し過ぎないようにしています。

濁音・半濁音は現時点では別の行として扱います（カ行とガ行、ハ行とバ行・パ行など）。小書き文字は対応する行に含めます（ャュョはヤ行など）。Discord共有では薄紫を 🟪 で表現します。

## v0.3: Discord内でチャンネル設定

v0.3から `KOTOBARU_LOG_CHANNEL_ID` / `KOTOBARU_SUMMARY_CHANNEL_ID` の手入力は不要です。
Botを起動したあと、「昨日の結果」を表示したいDiscordチャンネルで次を実行します。

- `/ことばル設定`：実行したチャンネルを結果表示先にする。非公開の `ことばル-記録` を自動作成する。
- `/ことばル設定確認`：現在の設定を確認する。
- `/ことばル集計テスト`：前日の記録がある場合、その場で集計投稿をテストする。

設定は `ことばル-記録` チャンネルのトピックに保存されるため、外部DBは不要です。Botやサーバーを再起動しても設定は復元されます。

Botには少なくとも「チャンネルの管理」「チャンネルを見る」「メッセージを送信」「メッセージ履歴を読む」が必要です。

## 判定色

- 緑（文字・位置とも一致）: `#4aa340`
- 黄（文字は一致、位置違い）: `#d5b222`
- 薄紫（五十音の行が一致）: `#9057a3`
- グレー（該当なし）: `#686868`
